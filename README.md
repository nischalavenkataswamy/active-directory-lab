# Active Directory Home Lab

## Overview

This project documents the creation of a Windows Active Directory environment designed to simulate a small enterprise network for SOC Analyst training.

## Environment

- Windows Server 2022
- Active Directory Domain Services
- DNS
- Windows 10 Domain Client
- VirtualBox

## Domain

corp.local

## Completed

- Installed Windows Server 2022
- Configured Active Directory
- Promoted Domain Controller
- Configured DNS
- Joined Windows 10 to the domain
- Created Organizational Units
- Created Security Groups
- Created Department Users
